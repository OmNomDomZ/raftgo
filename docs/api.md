# HTTP API этапа 2

| Маршрут | Результат |
| --- | --- |
| GET / | Встроенный UI этапа 2 |
| GET /status, /election | Локальный node, members, consistency=local, entries |
| GET /log | Локальный node, consistency=local, entries |
| POST /entries | {"command":"строка"}; 201 после commit/apply, index/term/committed |
| GET /cluster/status | Неатомарный опрос участников, доступность/время/статус |
| GET /cluster/log/{id} | Локальный лог известной реплики для UI |
| POST /cluster/entries/{id} | Same-origin add через известную реплику |

Запись лога: index, term, kind=command/noop, command, committed. Диагностика
включает неподтверждённый хвост. node и entries одного узла сняты под одним mutex.
Строка не интерпретируется; пустые строки и дубликаты допустимы. Лимит 65536 байт
UTF-8 после декодирования; требуется одно JSON-тело с полем command типа string,
без неизвестных полей. Неверные тела/UTF-8 и превышение лимита дают 400.

Follower: 307 Location на известного лидера, иначе 503. 201 означает commit
и apply своей пары index/term. 409 означает замену записи до commit. Ожидание
до 5 секунд, затем 504 с index/term и неизвестным исходом: это не откат,
автоповтор может создать дубликат. Применение всех follower не ждётся.

Маршруты UI ограничены фиксированным составом. Чтение лога имеет дедлайн
600 мс, запись — 8 секунд. Пересылка записи допускается только по явному 307
на точный api_url/entries известного участника. Произвольные URL, пути,
заголовки и cookies не пересылаются. После ошибки сети/503/504 повторов нет.
Агрегат выборов имеет atomic=false и не является снимком кластера.

RPC на отдельном private listener: POST /raft/request-vote,
POST /raft/append-entries. Прикладные команды не отправляются через RPC из UI.
