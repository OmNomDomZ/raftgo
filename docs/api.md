# HTTP API этапа 2

Swagger: `GET /swagger/`; OpenAPI: `GET /swagger/openapi.json`.
Спецификация содержит только доступные операции этапа 2.
[Запуск и показ](demo-launch.md).

| Маршрут | Результат |
| --- | --- |
| GET /status | Локальные node, members, consistency=local, entries |
| GET /log | Локальные node, consistency=local, entries |
| POST /entries | {"command":"строка"}; 201 после commit/apply с index/term/committed |
| POST /cluster/entries/{id} | Передача записи через выбранного участника к лидеру; удобно для Swagger |

Встроенный UI, `/election`, `/cluster/status` и `/cluster/log/{id}` удалены
и возвращают 404. Корневой `/` и прежние `/ui/...` также возвращают 404.

## Диагностика и запись

Запись лога: index, term, kind=command/noop, command, committed. Диагностика
включает неподтверждённый хвост. Node и entries одного узла сняты под одним
mutex. Members — конфигурация участников, а не их текущие статусы. Запросы
разных реплик не образуют атомарный снимок. Для других реплик откройте
`/swagger/` на портах 18002–18005; Swagger не обновляет ответ автоматически.

Строка не интерпретируется; пустые строки и дубликаты допустимы. Лимит —
65536 байт UTF-8 после декодирования. Требуется один JSON-объект с полем
command типа string, без неизвестных полей. Неверный JSON/UTF-8 и превышение
лимита возвращают 400.

Follower на прямой POST /entries возвращает 307 Location известного лидера,
без лидера — 503. Ответ 201 означает commit и apply своей пары index/term,
не применение всеми follower. Ответ 409 — запись заменена до подтверждения.
Ожидание до 5 секунд, затем 504 с index/term и неизвестным исходом. Это не
откат; повторный POST может создать дубликат.

## Передача записи для Swagger

`server/entries_forward.go` регистрирует POST /cluster/entries/{id}.
Параметр id выбирается только из фиксированного состава. Общий timeout —
8 секунд. Передача лидеру допускается только по явному 307 на точный
api_url/entries известного участника. Произвольные URL, пути, заголовки и
cookies не пересылаются. После сетевой ошибки, 503 или 504 повторов нет.

В Docker `internal_api_url` (например http://node1:8080) нужен для внутренней
передачи, а `api_url` (http://127.0.0.1:18001) — для 307 клиенту на хосте.
Без внутреннего адреса используется api_url. Оба адреса заданы конфигурацией.
В браузере используйте `/cluster/entries/{id}`: прямое перенаправление с
follower `/entries` на другой origin может быть заблокировано CORS.

Raft RPC работают на отдельном private listener: POST /raft/request-vote
и POST /raft/append-entries. Swagger их не вызывает.
