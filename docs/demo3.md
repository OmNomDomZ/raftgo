# Показ этапа 3: KV CRUD

Снимок `lab3` содержит выборы, строковый лог и строковый KV с Create/Get/Put/Delete.
Разработка продолжается в `main`; снимок не мержится обратно.

## Проверки и запуск

Нужны Go версии из go.mod, Docker Compose и Python 3.9+.

```sh
go build ./...
go test -count=1 ./...
go test -race -count=1 ./...
go vet ./...
gofmt -l .
docker compose -p raftgo-scenarios -f scenarios/compose.yaml up -d --build
python3 scenarios/run.py all
```

В lab3 `all` выполняет только task1–3.
Runner проверяет выборы, репликацию, замену неподтверждённого хвоста, CRUD,
сохранение значения при смене лидера и pause/unpause всех пяти процессов,
отказ GET/PUT без кворума. При ошибке печатает диагностику и восстанавливает
сети/паузы в finally. Процессы не перезапускаются с пустой памятью.

## Проверка в браузере

Откройте http://127.0.0.1:18001/ доступного узла. Экран отмечен «Этап 3».

1. Проверьте пять карточек, текущие голоса, локальный строковый лог и add.
2. В CRUD выберите follower и новый ключ. Create строки — 201, повтор — 409;
   Get возвращает первоначальное значение. Put меняет значение (200), Delete
   удаляет (200), Get и повторный Delete отсутствующего — 404.
3. Проверьте пустую строку, Unicode, кавычки, перенос строки и HTML как текст.
   Результат Get отделён от диагностики и сохраняется при фоновом опросе.
4. Поставьте лидера на паузу командой compose pause nodeN. Дождитесь выборов,
   прочитайте подтверждённое значение через живой follower. На карточке паузного
   узла должны быть видны недоступность и устаревание. Верните узел через unpause.
5. Поставьте три follower на паузу. PUT прежнему лидеру не должен завершиться
   успехом: 504 с index/term означает неизвестный исход. После утраты лидерства
   возможен 503. GET без кворума не возвращает успешное старое значение.
   UI очищает прежний ответ и не повторяет изменения автоматически.
6. Снимите паузы, дождитесь выборов; проверьте CRUD и узкий экран.

Запускайте runner и ручные отказы последовательно. Восстановление после 504
может применить исходную запись; 504 не означает откат. Опрос статусов локальный
и неатомарный; GET KV требует кворумного барьера и ожидания apply.

```sh
docker compose -p raftgo-scenarios -f scenarios/compose.yaml unpause
docker compose -p raftgo-scenarios -f scenarios/compose.yaml down
```

Полный down/up создаёт новый пустой кластер. Не возвращайте отдельный процесс
с пустой Memory под прежним ID в продолжающийся кластер.
