KV · CRUD, CAS и lock

GET читает через кворумный барьер и ждёт apply. Его результат отделён от локальных диагностических снимков выше. Это ответ на момент запроса, он не обновляется опросом состояния.

Токен передаётся только из этого поля, явно для CRUD / CAS / Unlock. Для Lock поле игнорируется. После смены ключа поле очищается.

Токены, полученные этой вкладкой

    Токены хранятся только в памяти этой страницы, не передаются другой вкладке автоматически и теряются при перезагрузке или закрытии. Сохраните токен вручную до ухода. Потерянный токен восстановить через UI нельзя. Нет TTL и auto-unlock: закрытие вкладки, удаление значения, таймаут и смена лидера не освобождают lock. Захват возможен и без значения; lock не реентерабелен. Токен действует только в одной жизни кластера; после полного сброса стенда старые токены не используйте.
