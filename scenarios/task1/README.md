# 1. Каркас, выбор лидера, статус ноды

Запуск: `bash scenarios/task1/run.sh` из корня после запуска [стенда](../README.md).

| Шаг | Действие | Ожидаемый результат |
| --- | --- | --- |
| 1.1 | Опросить `/status` и `/election` всех пяти нод | Один `Leader`, четыре `Follower`, одинаковый `term` и `leader_id`, `quorum=3`, корректный `id`, `running=true` |
| 1.2 | Остановить текущего лидера | Среди четырёх оставшихся появляется другой лидер; term растёт |
| 1.3 | Запустить прежнего лидера | Он присоединяется как follower, все снова согласны по term и лидеру |
| 1.4 | Остановить три ноды, включая лидера | В течение пяти секунд наблюдения ни одна из двух оставшихся нод не становится лидером |
| 1.5 | Восстановить остановленные ноды | Кластер снова выбирает единственного лидера |

Для демонстрации оставьте рядом окно с debug-логами: там видны запросы голосов,
смены term и ролей. Поле `votes` — текущие голоса кандидата, а не история голосования.
Итог автоматической проверки: `PASS task1`.
