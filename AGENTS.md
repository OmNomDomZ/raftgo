# Принятый снимок лабораторной 1

Эта ветка — результат сдачи: выборы и heartbeat, Memory с term/votedFor,
HTTP-диагностика и Swagger; встроенный экран удалён по поручению пользователя. Разработка выполняется в main в исходном
checkout. Не разрабатывать в lab1 и не мержить снимок обратно в main.
Пересдача/перемещение принятой lab1 требует отдельного поручения пользователя.

Контракт: docs/stages.md. Инструкции запуска: README.md, docs/demo-launch.md.
Безопасная память сохраняется при pause/unpause; не возвращать процесс с
пустым Storage под прежним ID в продолжающийся кластер.
