# lab2 — снимок этапа 2

Снимок подготовлен из main `c0c3138452e599c5980be8fe8f2040f932119b11`.
Возможности: выборы, heartbeat, репликация строкового лога, no-op, commit/apply,
локальная диагностика и встроенный UI этапа 2. Изменения разрабатываются в main;
не разрабатывать в lab2, не мержить снимок обратно. Пересдача — отдельное поручение.

Storage только в RAM: при отказах pause/unpause или сетевая изоляция сохраняют
term, голос и лог. Не возвращать пустую память того же ID в живой кластер.
504 означает неизвестный исход, автоматический повтор записи запрещён.
Диагностика локальна; опросы нескольких узлов неатомарны.

Проверки: `go build ./...`, `go test ./...`, `go test -race ./...`,
`go vet ./...`, `gofmt -l .` (пусто), Docker task1–2 и браузерный UI.
Инструкция запуска — README.md, лист показа — docs/demo2.md.
